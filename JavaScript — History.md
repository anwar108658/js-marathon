# JavaScript — History

## 1. Who created JavaScript?

**Brendan Eich** created JavaScript in **1995** while working at **Netscape**.

He initially created it in about **10 days**.

---

## 2. What was JavaScript originally called?

JavaScript had several names during development:

```text
Mocha → LiveScript → JavaScript
```

It was finally released as **JavaScript**.

> Despite the name, JavaScript is **not a version of Java**.

---

## 3. Why was JavaScript created?

The main goal was to make web pages **interactive and dynamic**.

For example:

```js
button.addEventListener("click", () => {
    alert("Hello!");
});
```

Before JavaScript, web pages were mostly static HTML documents.

---

## 4. What is ECMAScript?

**ECMAScript** is the **standard/specification** that defines how the JavaScript language should work.

JavaScript is an implementation of the ECMAScript specification.

```text
ECMAScript = Standard
JavaScript = Implementation
```

---

## 5. Important Versions

### ES5 — 2009

Major standardization and improvements.

### ES6 / ES2015 — 2015 ⭐

A very important release. Introduced:

```js
let
const
arrow functions
classes
template literals
destructuring
modules
promises
```

Modern JavaScript heavily uses ES6+ features.

# Interview Questions

### Q1. Who created JavaScript?

**Brendan Eich**, in 1995 at Netscape.

### Q2. Is JavaScript related to Java?

**No.** They are separate programming languages.

### Q3. What is ECMAScript?

ECMAScript is the specification/standard that defines the JavaScript language.

### Q4. What is ES6?

ES6, also called **ECMAScript 2015**, was a major JavaScript update that introduced features such as `let`, `const`, arrow functions, classes, promises, and modules.

### Quick Timeline

```text
1995 → JavaScript created
1997 → ECMAScript standardized
2009 → ES5
2015 → ES6 / ES2015
2015+ → New ECMAScript versions released regularly
```

### Remember

**JavaScript ≠ Java**

**ECMAScript = JavaScript standard/specification**
